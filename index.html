Sonotheca

一款开源的本地音乐管家：多来源下载、自动归档、内嵌歌词与沉浸式播放，把你的曲库收进一只深海里漂浮的玻璃水母。

功能特性

一个瓶子，装下整片音乐海洋

从下载到播放，从归档到美化，Sonotheca 把音乐链路串成一条顺畅的体验。

多来源搜索与下载

在网易云音乐、QQ音乐、B站与 Navidrome 之间搜索音乐，浏览歌单与收藏夹；下载任务进入队列统一管理，并发数与限速可控，完成后自动写入标签并按你的规则归档到本地。

本地音乐库

扫描登记整个本地曲库，分页加载保持流畅；按歌名、歌手、专辑甚至路径快速检索，封面缩略图一眼定位，批量操作省去重复点击。

元数据与歌词

自动补全缺失的歌曲标签，把歌词写进文件内嵌；支持标准 LRC 歌词格式，让歌词与音乐同步跟唱。

沉浸式播放器

迷你播放条随手即控，全屏播放页专注聆听；歌词随音乐逐行滚动、逐字高亮，上一首 / 下一首 / 进度拖动一气呵成。

播放列表与文件管理

双窗格文件管理器：复制、移动、重命名、删除随手完成，误删可进回收站找回；播放列表自由编排你的听歌顺序。

外观个性化

浅色 / 深色 / 跟随系统随心切换，动态取色让界面与当前封面呼应；内置深海壁纸与液态玻璃毛玻璃效果，氛围感直接拉满。

技术栈

现代而克制的工程组合

Tauri 2 负责轻量外壳，Vue 3 驱动界面，Rust 承担重活，SQLite 记录每一首音乐的来处。

Tauri 2

跨平台桌面壳与移动打包，轻量且快

Vue 3

响应式界面与组件化的前端核心

TypeScript

类型安全的前端与业务逻辑层

Rust

下载、解析与本地文件的性能担当

SQLite

零配置的本地音乐档案存储

界面预览

深海里的液态玻璃
