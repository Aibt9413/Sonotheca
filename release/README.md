# Sonotheca v1.0.19

首个公开正式版。

## 文件

- `Sonotheca-1.0.19-release.apk` — Android 安装包，使用开发测试签名，直接安装体验。
- `Sonotheca-1.0.19-source.zip` — 完整源码压缩包（含 Android 原生工程、图标与文档）。

## 安装

1. 下载 APK；
2. 手机允许安装未知来源应用；
3. 安装后授予通知、存储/所有文件访问权限；
4. 在设置中选择自己的音乐库目录。

包名：`com.aibt.sonotheca`

## 本版内容

- 多来源搜索：网易云 / QQ 音乐 / B 站 / Navidrome
- 下载队列、并发数与全局限速
- 本地音乐库分页、搜索、内嵌封面缩略图
- 元数据自动补全与手动编辑
- MP3 `USLT` / FLAC `LYRICS` 内嵌歌词
- 标准 LRC、前缀多时间戳、内联逐字 LRC 与逐字高亮
- 本地与在线播放器、迷你播放条、全屏播放页
- 双窗格文件管理与回收站
- MD3 主题、壁纸、液态玻璃、动态取色
